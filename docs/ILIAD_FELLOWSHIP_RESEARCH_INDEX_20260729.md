# AI-safety mathematics and identity geometry

## Fellowship research index

This repository develops two connected research programs:

1. **AI Safety Millennium Problems (ASMPs):** versioned mathematical problems
   about mechanistic identifiability, distribution shift, weak verification,
   evaluator-relative control, recursive modification, collusion, and
   capability attestation. Each problem has a two-sided resolution rule,
   explicit claim boundary, prior-art gate, and independently checkable
   computational artifacts.
2. **Identity geometry for mechanistic interpretability:** a spectral-bundle
   and holonomy framework for testing whether a learned feature, monitor, or
   edit coordinate retains a consistent identity across contexts, checkpoints,
   and runtime precision.

The project treats negative results as first-class outcomes. The original seven
ASMPs have bounded problem-specific work, but none is claimed resolved at its
full scope. The holonomy program has validated synthetic instruments and
produced bounded Qwen-0.8B results; it does not claim that transformer
capabilities are topological.

## Research posture

The common question is: **when does a measurement continue to name the same
decision-relevant object after an interface, context, model, or evaluator
changes?** The ASMP program turns that question into versioned mathematical
frontiers. The identity-geometry program turns it into executable
certificates, falsification gates, and visual tools. Neither program promotes
instrument validation into evidence for recursive self-improvement or
large-model safety.
