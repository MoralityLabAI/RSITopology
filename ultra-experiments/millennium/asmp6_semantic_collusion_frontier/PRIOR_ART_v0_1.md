# ASMP-6 v0.1 prior-art boundary

This experiment is not presented as new steganographic coding theory.

- Simmons's prisoners' problem supplies the covert-coordination setting.
- Cachin's information-theoretic model defines steganographic security using
  the cover-first relative entropy `D(P_cover || P_stego)`. The protocol keeps
  that orientation explicit and separately records the reverse orientation.
- Classical steganographic and covert-communication square-root laws concern
  asymptotic scaling. This finite four-symbol census supplies no evidence for
  or against those laws.
- Arbitrarily varying channels with state constraints supply the closest
  mathematical ancestor for a charged active auditor. Here the state/action
  class is finite and exhaustively enumerated, not a new AVC theorem.

The bounded contribution is the prospectively frozen comparison of
mixture-only versus per-message covertness under one exact finite active-audit
registry. Its purpose is instrument validation and access-class separation.
