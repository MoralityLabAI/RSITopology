## Why the remaining gap is upstream

The dependency order is now explicit:

`formal registered class -> public abstraction or replacement`

`-> port-specific cost profiles -> region computation`.

The final region-computation node is closed for finite additive quotients, and
the port-specific transfer laws are available. The first two nodes remain
missing. A global finite-horizon margin theorem also depends on both.

The frozen phrase “registered normally hyperbolic, locally controllable class”
does not provide a formal grammar over admissible plant maps, observation
experiments, timing, randomness, actuator decoders, cost functionals, or
quotient equivalence. The conservative v0.15 clause audit found seven ambiguous
clauses, one parameterized selector, and an external adjudication queue that is
still pending. Choosing one completion autonomously would change the problem.

## Why a finite quotient cannot simply be imposed

V0.26's Thue-Morse chain has exact rate `1/2` and no finite exact stationary
quotient. Thus finite exact abstraction is sufficient, not necessary. Making
it part of the canonical answer would exclude systems whose rates remain
simple and computable.

Nor does quotient state count control every registered cost. V0.28 shows that
one state class can hide exponential terminal-history fibers; v0.29 shows that
terminal-bijective maps can hide local branch entropy; v0.30 shows that even
unrounded local-fiber products miss sequential Kraft rounding. An acceptable
global abstraction theorem must state which cost profile it preserves.

## Why another bounded harness cannot close the gap

A bounded harness can falsify a proposed formal grammar, abstraction theorem,
or finite-horizon formula. It cannot quantify a class the source has not
defined, infer a uniquely intended semantics after the v0.15 audit rejected
that inference, or prove existence of an abstraction for arbitrary continuous
belief dynamics by enumerating more finite games.

The decisive issue is no longer compute scale. V0.31 exhaustively validates
the finite adversarial endpoint. Extending its state count would add examples
inside a lane whose theorem is already exact.

## Reopening conditions

Resume mathematical construction only when at least one of these occurs:

1. A formal global grammar specifies admissible nonlinear plants, sensors,
   timing, randomness, costs, actuator decoders, and quotient equivalence.
2. A concrete public-abstraction theorem or nonfinite variational replacement
   is proposed with checkable hypotheses for such a grammar.
3. Attributable external adjudication maps the frozen wording to one established
   formal class.
4. A demonstrated error invalidates a sealed premise of this stopping argument.

Under condition 1 or 2, the existing harness can immediately test the proposed
construction, cost-profile preservation, adversarial region, and finite-horizon
margin. Under condition 3, it can rerun the requirement ledger against the
selected semantics. Condition 4 reopens the affected dependency directly.

## Conclusion

The evidence supports a convincing harness-backed operational stop on further
autonomous bounded expansion. It does not support saying ASMP-4 is solved, and
it does not support saying no global theorem exists. The correct next input is
a formal class plus abstraction theorem, attributable semantic adjudication,
or a concrete falsification of this certificate—not another local fixture.
