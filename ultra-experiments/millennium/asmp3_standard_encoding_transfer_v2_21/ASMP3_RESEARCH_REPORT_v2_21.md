# ASMP-3 research report through v2.21

## Executive result

The research now supplies an internal negative resolution of the unrestricted
standard-encoded membership problem under both natural protocol quantifiers.
For every adequate effective representation of canonical ASMP-3 families,
membership in the full constant-gap class is undecidable and its positive set
is not recursively enumerable. Allowing the protocol to select an interface
does not change the reduction: after the encoded machine halts, opposite-answer
worlds have identical transcript laws under every semantic-respecting
interface.

This meets v0.1's explicit mathematical route—undecidability of the associated
frozen uniform decision family—under its ordinary “standard encodings of
computation” convention. It is not yet prize-grade acceptance because v0.1 is
a definition draft without literal parser/type closure and the external gate is
still 0/2.

## 3. Full-set representation transfer

For any standard encoding `D` able to compile the elementary bounded-simulation
game, the total compiler `C_D` maps machine indices into valid instances of the
full `D`-encoded ASMP-3 decision domain. V2.20 gives

```text
C_D(e) is positive  iff  e does not halt.
```

A decider for the full domain would therefore decide `NONHALT`. The structured
compiler image is the witness used by the reduction; it is not the theorem's
replacement domain.

Three independently decoded representations—JSON AST, register IR, and circuit
IR—exercise the transfer mechanics. The universal theorem is conditional only
on five explicit adequacy axioms: decidable syntax, total compiler, semantic
preservation, extensional membership, and inclusion of valid compiler outputs
in the full domain.

## 4. FIX/ADM transfer

Suppose the machine has halted. Use the even world `0^d` and odd world
`10^(d-1)`. In each world, the false labelled prover emulates the honest
algorithm for its label on the other fixed world. With coins coupled by label,
the complete interaction remains identical round by round. The semantic oracle
is world-independent zero, so every adaptive noisy answer can also be coupled.

The verifier consequently has the same output law in worlds requiring opposite
labels. No selected interface can have positive gap unless it adds a trusted
world-dependent channel outside the declared environment.

If the machine never halts, the certified vector interface supplies gap `3/5`.
Therefore the reduction works for strict FIX, singleton ADM, and every broader
ADM class containing the vector interface while preserving verifier
information.

## 6. Interpretation of “resolved”

Mathematically, the ordinary unrestricted program-encoded decision problem has
a negative resolution. Institutionally, the draft does not have a unique
machine grammar or the two external reviews required for a prize-grade claim.
The right status is therefore:

```text
internal theorem = full-set undecidability across FIX/semantic-respecting ADM
parent status = negative-resolution candidate under ordinary standard encoding
external status = open, 0/2 reproductions
```

This is stronger than saying ASMP-3 is “impossible.” Exact positive subclasses
and every fixed finite depth remain meaningful and certifiable. The theorem
locates the impossibility at uniform algorithmic membership over arbitrary
program-generated families.

## 7. Recommended stopping point

Further finite simulation cannot decide the remaining institutional question.
The next useful input must be one of:

- an authoritative parser and information structure;
- a proposed restricted successor class excluding the compiler image; or
- independent expert review of admissibility and the two transfer proofs.

If a restricted successor is proposed, the existing finite, noise, encoding,
and resource theorems provide the right starting tools. Until then, the
mathematical lane has reached a proof-backed stopping boundary.
