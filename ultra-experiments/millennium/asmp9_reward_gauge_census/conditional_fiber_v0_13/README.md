# ASMP-9 conditional-fiber quotient v0.13

This is an unregistered CPU-only theorem-development directory.

The target is an exact conditional experiment for finite Bradley-Terry
comparison counts. Conditioning on the vertex win-balance statistic removes
the scalar-utility nuisance. The remaining conditional law depends only on
the cycle-space quotient of the edge log odds.

The central liveness rule is data-dependent: a conditional fiber identifies
only the directions spanned by differences between count vectors in that
fiber. A singleton or rank-deficient fiber must not be treated as evidence of
scalar coherence.

No file in this directory is claim-eligible until a later protocol and
registration explicitly freeze it.
