# Finite history valuation: Markov factorization or canonical replacement

Status: **proved finite theorem; development-only and unregistered**.

## 1. Problem

ASMP-9 asks for a no-go theorem when a demonstrator does not admit the
declared coherent scalar value object. A useful no-go should also say what
object remains identifiable.

Freeze:

- a finite directed multigraph with labelled edges `E`;
- one registered start state;
- a finite horizon `H`;
- the complete prefix-closed set `P_H` of reachable edge paths; and
- an exact path valuation `F : P_H -> R`.

The first candidate object is a stationary Markov edge reward `r in R^E`:

```text
F(p) = F(empty) + sum_e count_p(e) r_e.
```

## 2. Exact Markov-factorization theorem

Let `X` be the path-edge incidence matrix:

```text
X[p,e] = count_p(e),
```

and let

```text
f[p] = F(p)-F(empty).
```

### Theorem 1

The following are equivalent:

1. `F` is generated by a stationary Markov edge reward;
2. the linear system `X r = f` is consistent;
3. `f` lies in the column space of `X`; and
4. every path relation `a in ker(X^T)` satisfies `a^T f=0`.

When the conditions fail, any

```text
a in ker(X^T) with a^T f != 0
```

is an exact history-interaction certificate. It combines registered paths so
that every edge count cancels while the claimed path values do not.

#### Proof

Items 1–3 are the definition of factorization. By the finite-dimensional
fundamental theorem of linear algebra,

```text
col(X) = ker(X^T)^perp,
```

which proves item 4 and the obstruction statement.

### Access consequence

The complete path table identifies the Markov edge reward only modulo
`ker(X)`. If reward gauge `G` is separately licensed, the intended quotient
is identified exactly when

```text
ker(X) = G
```

after the v0.69 joint measurement quotient. Markov factorization and reward
identification are therefore distinct gates:

```text
F in col(X)       tests whether a Markov reward exists;
ker(X)=G          tests whether its licensed quotient is identified.
```

Selecting a least-squares edge reward when `F` is outside `col(X)` does not
make the residual history dependence disappear.

## 3. Canonical bounded-horizon replacement

Failure of Theorem 1 does not imply that the valuation is meaningless. It
implies that the original graph state is insufficient.

For history `h`, let:

- `v(h)` be its endpoint;
- `k(h)=H-|h|` be its remaining horizon; and
- `Z(h)` be every valid suffix of length at most `k(h)`.

Define future-increment equivalence:

```text
h ~ h'
```

exactly when:

1. `v(h)=v(h')`;
2. `k(h)=k(h')`; and
3. for every common valid suffix `z`,

```text
F(hz)-F(h) = F(h'z)-F(h').
```

Histories with the same endpoint and remaining horizon have the same suffix
domain, so the comparison is total.

### Theorem 2: canonical endpoint-respecting reward-machine quotient

The equivalence classes `[h]` form a deterministic bounded-horizon augmented
state system. For valid next edge `e`, define:

```text
delta([h],e) = [he],
rho([h],e) = F(he)-F(h).
```

Both definitions are independent of the representative `h`, and:

```text
F(e_1...e_T)
  =
  F(empty)
  + sum_t rho([e_1...e_(t-1)], e_t).
```

Moreover, every deterministic bounded-horizon state representation that
retains the registered endpoint and remaining-horizon labels and makes all
future increments Markov must distinguish histories in different `~`
classes. Hence this quotient is minimal up to relabelling inside that
endpoint/time-respecting class.

#### Proof

Suppose `h~h'`. Applying the definition to suffix `e` gives equal immediate
increments. Applying it to `ez` and subtracting the equality for `e` gives:

```text
F(hez)-F(he) = F(h'ez)-F(h'e)
```

for every remaining suffix `z`; therefore `he~h'e`. Transition and reward
are well-defined. The path identity telescopes.

For minimality, if `h` and `h'` are inequivalent, they either carry different
registered endpoint/time labels or some suffix has different increment. Any
endpoint/time-respecting state representation merging them would violate the
labels or assign one future transition/reward behavior to both and fail on
that suffix.

This is the weighted bounded-horizon analogue of Myhill–Nerode minimization.

## 4. When original Markov state suffices

The original graph state with remaining horizon is sufficient exactly when
every two registered histories sharing `(endpoint,remaining)` are
future-increment equivalent.

If this holds and the valuation is stationary across remaining horizons,
Theorem 1 recovers an ordinary edge reward. If it fails, at least one original
state must split by history. The number and structure of these splits are a
finite, exact measure of the required memory.

## 5. Reconvergent multigraph witness

Use three states and three edges:

```text
a : s -> m
b : s -> m
z : m -> t.
```

Set every registered prefix value to zero except:

```text
F(a,z)=1,
F(b,z)=0.
```

The prefix values force:

```text
r_a=r_b=0.
```

The two length-two paths then require both `r_z=1` and `r_z=0`. The exact
left-kernel certificate cancels the edge counts and leaves residual one.

Histories `(a)` and `(b)` have the same endpoint and remaining horizon but
different value for suffix `(z)`, so the canonical replacement splits them.
The replacement replays every registered path exactly.

A matched additive fixture with:

```text
r_a=1, r_b=2, r_z=3
```

recovers those rewards and does not split the two histories at `m`.

The verifier also exhausts all `16` binary assignments to the four nonempty
path values on this graph. Exactly `6` factor through a Markov edge reward and
`10` do not. Exactly those `10` require a history split at the reconverged
state, and all `16` canonical replacements replay exactly. This is a complete
census of the frozen fixture, not a general prevalence claim.

## 6. ASMP-9 consequence

For the registered finite path class, v0.71 gives a total object-selection
rule:

```text
if F in col(X):
    report a Markov edge-reward orbit, subject to the access kernel;
else:
    reject the Markov scalar object,
    emit an exact path relation witness,
    and report the minimal endpoint/time-respecting augmented
    future-increment state quotient.
```

This is stronger than fitting a scalar and reporting residual error: the
obstruction is exact, and the replacement has a minimality theorem.

## 7. Claim boundary

Path incidence, linear factorization, Myhill–Nerode equivalence, weighted
automata, and reward-machine constructions are classical. No novelty is
claimed for those ingredients.

Version v0.71 covers a complete exact bounded finite path language. It does
not establish:

- how to acquire all path values from a human or model;
- finite-sample tests with noisy or missing paths;
- infinite-horizon finiteness of the replacement;
- stochastic, continuous, multi-agent, or strategic history dependence;
- that the registered path valuation is morally valid; or
- resolution of ASMP-9.
