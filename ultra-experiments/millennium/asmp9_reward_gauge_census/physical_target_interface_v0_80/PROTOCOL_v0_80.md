# ASMP-9 controlled physical target-interface protocol v0.80

Status: **prereveal protocol; no registered outcome has been executed**.

## Question

In one exactly auditable finite-MDP response channel, can stochastic response
samples recover registered policy margins while:

1. remaining population-invariant to licensed potential shaping;
2. separating matched-norm non-gauge reward changes; and
3. retaining its error certificate under a frozen per-sample TV
   misspecification radius?

## System

The MDP has one start state, deterministic left/right intermediate states, and
one terminal state. The four reward coordinates are:

```text
(start-left, left-terminal, start-right, right-terminal).
```

The registered target is the left-minus-right route-return margin.

Four contexts are frozen:

```text
construction margins:  1/4,  3/4
holdout margins:       -1/4, -3/4.
```

## Arms

The base edge reward is `(0, margin, 0, 0)`.

Licensed shaping delta:

```text
(3/5, -3/5, 4/5, -4/5).
```

It has zero route-margin effect and is generated by the state potential
`Phi(start)=0, Phi(left)=3/5, Phi(right)=4/5, Phi(terminal)=0`.

Matched non-gauge delta:

```text
(1, 0, -1, 0).
```

Both deltas have exact squared Euclidean norm two. The non-gauge delta changes
the target margin by two.

For every context, execute:

```text
base
shape_plus
shape_minus
nongauge_plus
nongauge_minus.
```

## Response channel

The controlled demonstrator is an exact softmax planner. For inverse
temperature `beta` and target margin `m`:

```text
Pr(left | beta,m) = sigmoid(beta*m).
```

Queries use `beta in {0.5,1,2}`. Each context/arm/query cell receives 512 iid
Bernoulli samples. Seeds are SHA-256-derived from the global seed and complete
candidate ID.

This channel is deliberately simple: it validates the acquisition and
adjudication stack under a known response law. It is not evidence that humans
or language models use softmax planning.

## Frozen gates

### W0 — exact well-posedness

Pass iff, in exact rational arithmetic:

- both shaping arms preserve every context target;
- both non-gauge arms change every context target; and
- shaping and non-gauge deltas have equal squared norm.

### I0 — byte-identical replay

The registered executor runs the complete response generator twice. Pass iff
both `response_rows.jsonl` and `result.json` are byte-identical. Any mismatch
is `invalid_instrument`.

### R0 — margin recovery

For each context/arm, apply Jeffreys correction independently at each beta,
invert the registered logit, and average the three margin estimates.

Pass iff:

```text
maximum absolute error <= 0.15
and every estimated margin has the correct sign.
```

Equality passes.

### L0 — representative leakage

For each context/beta, compare empirical left-choice rates for each shaping arm
against base.

Pass iff the maximum absolute difference is at most `0.12`. This finite-sample
gate does not replace the exact population identity, which follows from equal
target margins.

### M0 — misspecification robustness

Across all distinct registered target margins, compute the v0.77
Hellinger-affinity union bound for the complete three-query, 512-sample
response. Add:

```text
1-(1-epsilon)^(3*512), epsilon=1e-5.
```

Pass iff the robustified bound is at most `0.05`. Equality passes.

## Fixed sequence

```text
W0 -> I0 -> R0 -> L0 -> M0.
```

Only pass opens the next gate. Instrument invalidity returns
`not_evaluated`; fail or inconclusive stops. No threshold may be changed after
registration.

## Required outputs

- `primary/response_rows.jsonl`
- `primary/result.json`
- `primary/run_receipt.json`
- byte-identical replay equivalents
- `adjudication.json`
- `execution_receipt.json`

The receipt hashes the registration, both generated runs, and adjudication.

## Claim boundary

A pass validates one controlled softmax-planner acquisition channel and its
implementation. It does not identify human/model values, validate softmax as a
behavioral law, establish the moral adequacy of policy margins, generalize to
open-ended environments, or resolve ASMP-9.
