# ASMP-9 resolution-obligation matrix after v0.65 development

## Verdict

**ASMP-9 remains unresolved.**

Version v0.65 maps the static strategic ordinal branch.  Deterministic
outcome-only elicitation has an exact finite capacity; classical random
problem selection restores full-ranking elicitation under additional
commitment and expected-utility assumptions.  The package is deliberately
unregistered because these are classical or elementary finite results, not a
new test of a load-bearing scientific uncertainty.

## What v0.65 adds

### Deterministic strategic capacity

For a finite strict-ranking type domain, the exact number of types that can be
strictly incentive-identified by an arbitrary interactive deterministic
outcome-only protocol is

```text
max over nonempty A subseteq X
  |{top_A(theta): theta in Theta}|.
```

On the full ranking domain this is `n`, not `n!`.

### Classical randomized escape

When a complete report is committed before an objective random pair is drawn,
awarding the reported winner strictly elicits the full ranking exactly when
all pairs have positive probability.  Support `C(n,2)` is necessary and
sufficient.  This mechanism is explicitly prior art in Azrieli, Chambers, and
Healy (2021).

### Margin and timing

With unit-range expected utility and adjacent gaps at least `delta`, uniform
pair sampling has sharp worst false-report regret `delta/C(n,2)`.  Without a
cardinal gap there is no uniform numerical margin.  If the pair is revealed
before reporting, each answer leaves `n!/2` full rankings equivalent.

The independent audit checks 15,016 report comparisons and 55 missing-pair
witnesses in addition to the deterministic census.

## Registration decision

The [registration decision](strategic_elicitation_capacity_v0_65/REGISTRATION_DECISION_v0_65.md)
keeps v0.65 development-only.  A prospective seal would reproduce a known
random-problem-selection mechanism rather than close the physical or dynamic
uncertainty that now limits ASMP-9.

## Remaining load-bearing sequence

### A. Dynamic strategic response

Replace the static type by a declared target process.  Freeze:

1. whether the target changes before or after each consequence;
2. which histories the responder and experimenter observe;
3. whether reports commit before random problems are sampled;
4. whether the intervention changes the target being measured; and
5. the decision loss defining equivalence between target processes.

The first theorem target should distinguish identification of an initial
value object from control or creation of a later one.

### B. Structured hidden consideration

The v0.64 intermediate class remains open.  Declare restrictions on hidden
consideration, preference dependence, repeated latent sets, and observability;
then compute or bound the separation-cover object without collapsing to
unrestricted singletons or verified exact pairs.

### C. General modulus computation or complexity

Extend the v0.63 exact capped-simplex result to a declared family of finite RUM
polytopes with exact dual certificates, or establish a sharp complexity
barrier for tier-modulus computation.

### D. Physical access validation

No theorem shows that a human or model implements the frozen response channel.
A prospectively registered bridge must test:

- whether the report is stable and genuinely committed before the draw;
- whether pair selection is treated as objective and independent;
- whether registered consequences causally affect reports;
- whether expected-utility and minimum-gap assumptions survive held-out
  choices;
- whether hidden consideration and recording gates pass; and
- whether the identified object improves a declared downstream decision.

## Claim boundary

The suite does not establish that humans or models possess a coherent latent
value object, that elicitation preserves rather than changes that object, that
random pair consequences are enforceable, or that the finite ranking target
has moral meaning.  Version v0.65 is a development-level access ledger, not a
resolution of ASMP-9.
