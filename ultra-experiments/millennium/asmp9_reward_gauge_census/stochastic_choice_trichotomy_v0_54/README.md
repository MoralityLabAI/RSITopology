# ASMP-9 finite stochastic-choice trichotomy v0.54

This package addresses the behavioral well-posedness gap left open by the
scalar-reconstruction work in v0.7-v0.13.

For a complete stochastic choice kernel on three alternatives, it separates:

1. a single positive Luce ratio scale;
2. a random-utility representation by a distribution over strict rankings,
   but no single Luce scale; and
3. no random-utility representation in the declared class.

The representation theorems are classical. The package contribution is an
ASMP-9 instrument: exact rational classification, explicit certificates,
matched access witnesses, and a prospective verification boundary.
