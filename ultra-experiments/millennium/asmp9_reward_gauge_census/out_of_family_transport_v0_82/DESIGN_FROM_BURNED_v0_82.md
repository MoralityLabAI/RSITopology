# Design from burned results

The following facts were known before v0.82 was frozen:

1. V0.68 construction and confirmation established the same local/global
   expressed-response pattern on different scenarios within the same twelve
   family labels.
2. V0.81 established a synthetic structured decoder only because exact
   intervention offsets were available to it.
3. V0.68 construction supplied a fixed center, max-residual envelope, and
   common-coefficient intersection.

Those facts select the new access question and set every v0.82 threshold.  No
v0.82 output was used to select the twelve new families or their text.  The
same-family v0.68 confirmation is not pooled with v0.82; it is historical
motivation only.
