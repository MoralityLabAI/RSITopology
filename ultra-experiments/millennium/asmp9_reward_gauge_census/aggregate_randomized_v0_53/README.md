# ASMP-9 aggregate randomized coverage v0.53

This package addresses the randomized seam left by deterministic completeness
v0.52.

Its central development result is not that randomization can improve discrete
confidence procedures—that is classical. It is that the thresholded
subset-bound table used by v0.48–v0.52 is no longer sufficient to determine
the optimum once coverage is averaged over external report randomization.

- `PRIOR_ART_GATE_v0_53.md`;
- `THEOREM_DRAFT_v0_53.md`;
- `aggregate_randomized.py`; and
- `test_aggregate_randomized.py`; and
- `DEVELOPMENT_RESULT_v0_53.md`.
