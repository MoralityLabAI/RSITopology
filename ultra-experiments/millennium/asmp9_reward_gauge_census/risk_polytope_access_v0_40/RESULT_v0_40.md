## General finite characterization

For decision problem `d`, let `R_d(E)` be the convex polytope of target-wise
risk vectors generated by randomized rules after experiment `E`. Define

```text
U_d(E) = R_d(E) + R_+^Theta.
```

Then the v0.38 rule-by-rule deficiency satisfies

```text
delta_D(E,F)
  = inf {epsilon >= 0:
         R_d(F) subset U_d(E)+epsilon*1
         for every d in D}.
```

This turns the ASMP-9 access question into an exact finite containment
problem. The compiler evaluates every query subset, reports exact rational
deficiency, and returns the inclusion-minimal access antichain at every
critical tolerance.

## Test Cover and the quantitative partition formula

For deterministic binary queries and zero-one target classification:

```text
delta_D(access, full) = 1 - 1/k,
```

where `k` is the size of the largest target block sharing one access
signature. Therefore:

```text
delta_D=0
  iff every target has a distinct signature
  iff the selected queries form a Test Cover.
```

Minimum-cardinality exact access selection is consequently the classical
NP-hard Minimum Test Cover problem.

The four-target confirmation produced:

| Tolerance | Inclusion-minimal classification access |
| ---: | --- |
| `0` | `{s0,s1}`, `{s0,sx}`, `{s1,sx}` |
| `1/2` | `{s0}`, `{s1}`, `{sx}` |
| `3/4` | empty access |

All sixteen classification rows matched both the block-size formula and the
Test Cover decision. Exact primal-dual solver spot checks matched at
deficiencies `3/4`, `1/2`, and `0`.

## Decision-type dependence

The query channels were held fixed. Only the registered loss type changed.

For a binary group decision with false-positive cost `c_fp` and
false-negative cost `c_fn`, a label-mixed block has exact deficiency

```text
c_fp*c_fn/(c_fp+c_fn),
```

while a label-pure partition has deficiency zero.

The disjoint asymmetric types gave:

| Decision type | Zero-tolerance minimal access | Empty-access critical tolerance |
| --- | --- | ---: |
| `s0` group, costs `(1/4,1)` | `{s0}`, `{s1,sx}` | `1/5` |
| `s1` group, costs `(3/5,4/5)` | `{s1}`, `{s0,sx}` | `12/35` |
| both group problems | `{s0,s1}`, `{s0,sx}`, `{s1,sx}` | `12/35` |

For the combined type, tolerance `1/5` changed the antichain to
`{s1}` and `{s0,sx}` before empty access became admissible at `12/35`.

Thus query informativeness is not a property of the channel alone. It is a
relation among the channel, the reference access, the loss type, and the
tolerance.

## Resolution significance

Versions v0.37–v0.39 showed why a zero-error quotient, full expanded
deficiency, and scalar leakage radius were each insufficient by themselves.
Version v0.40 supplies the general finite replacement object:

```text
declared decision type
  -> achievable risk polytope
  -> exact access-containment frontier
  -> minimal access antichain.
```

This closes the arbitrary-*finite*, registered-loss, nonadaptive
characterization. The remaining resolution work is to extend it to adaptive
query policies, finite samples, broad reward/response classes,
misspecification, strategic nuisance, and a valid real-model channel.

## Claim boundary

The risk-set characterization is classical Blackwell/Le Cam/Torgersen
decision theory. Test Cover and its NP-hardness are classical. The result
does not establish efficient solution of arbitrary instances, continuous
reward identifiability, human-value recovery, a transformer result, or
resolution of ASMP-9.
