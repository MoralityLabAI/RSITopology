# ASMP-9 sharp interior availability v0.15

This is an unregistered CPU-only theorem-development directory.

Version v0.14 proved that an unbounded scalar nuisance can preserve exact
conditional inference while driving unconditional informative-fiber
probability to zero. It restored a positive but deliberately conservative
lower bound under a declared probability interior.

This successor asks for the sharp equal-count minimax availability and exact
per-edge trial threshold over that interior. It also runs a bounded exact
allocation census to test—but not assume—that balanced integer allocation is
optimal under a fixed total budget.

No development output is claim-eligible.
