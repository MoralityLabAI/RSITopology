# ASMP-9 resolution-obligation matrix after v0.71 development

## Verdict

**ASMP-9 remains unresolved.**

Version v0.71 advances the general replacement-object obligation for one
finite history-dependent class. A complete bounded path valuation either
factors through a stationary Markov edge reward or emits an exact
path-incidence obstruction. In the latter case, future-increment equivalence
constructs the minimal endpoint/time-respecting bounded-horizon
augmented-state replacement.

The theorem is classical linear algebra and weighted-automata machinery
packaged as an ASMP-9 object-selection rule.

## Status against the five obligations

| Obligation | Strongest evidence after v0.71 | Status | Missing resolution evidence |
|---|---|---|---|
| 1. Maximal invariance or identifiability object | v0.69 gives the joint linear quotient; v0.71 selects Markov reward versus a minimal bounded history quotient for complete path values | **Exact for one finite history class** | Stochastic, continuous, infinite-memory, multi-agent, relational, and strategic target classes |
| 2. Necessary and sufficient access | Complete path values admit a Markov reward iff `f in col(X)`; the reward orbit is identified iff the remaining access kernel equals the licensed gauge | **Exact under complete path-table access** | Minimum path-query design, missing/noisy paths, adaptive interventions, and physical acquisition |
| 3. Sharp query/sample/intervention bounds | Incidence rank gives the noiseless parameter dimension | **Population linear rank only** | Sharp path-query count under structured languages, stochastic samples, computation, and conditioning |
| 4. Robustness to misspecification | Exact non-factorization is witnessed by `a in ker(X^T)` with `a^T f != 0` | **Exact noiseless obstruction** | Approximate distance to factorization, finite-sample testing, drift, missing paths, and adversarial responses |
| 5. No-go without a coherent latent value object | Non-Markov path valuations receive an exact no-go plus a minimal augmented-state replacement | **Class-level finite path branch addressed** | General criteria choosing relation-, stochastic-kernel-, set-, continuous-process-, or multi-agent replacements |

## New separation

Version v0.71 makes three questions independent:

```text
existence:
  does a Markov edge reward generate the path values?

identification:
  does the access kernel equal the licensed reward gauge?

replacement:
  if existence fails, what minimal history state reproduces future increments?
```

Gauge fixing cannot repair a failure of existence, and a lossless augmented
state encoding does not by itself establish moral or behavioral meaning.

## Next load-bearing steps

1. derive a sharp missing/noisy-path factorization test with a matching lower
   bound;
2. determine when the bounded-horizon quotient stabilizes as horizon grows,
   yielding a finite history machine rather than unbounded memory;
3. bind the path queries to a physical response channel; and
4. extend the replacement classification to stochastic kernels and
   incomplete/nontransitive relations.

## Claim boundary

Version v0.71 does not show that humans or models expose complete path values,
that the minimal encoding is an ethically valid value object, that the
replacement remains finite at unbounded horizon, or that ASMP-9 is resolved.
