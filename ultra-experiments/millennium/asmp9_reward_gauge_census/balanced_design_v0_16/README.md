# ASMP-9 balanced maximin design v0.16

This directory develops the unequal-count theorem left open by v0.15.

For a consistently oriented comparison cycle with a fixed total number of
independent Bernoulli trials and a declared probability interior, the proposed
theorem says that the unique maximin allocation, up to edge permutation,
assigns trial counts differing by at most one.

The proof uses a pairwise Robin-Hood transfer after minimizing over the
endpoint nuisance labels. It is not inferred from the finite census.

All files and outputs in this directory remain unregistered development until
a prospective v0.16 protocol and registration are committed.
