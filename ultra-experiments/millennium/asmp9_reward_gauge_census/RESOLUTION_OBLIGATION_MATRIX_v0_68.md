# ASMP-9 resolution-obligation matrix after v0.68 development

## Verdict

**ASMP-9 remains unresolved.**

Version v0.67.1 rejected the registered global three-state physical response
instrument. Version v0.68 supplies a classical maximal-invariant correction:
only within-context/order contrasts descend through the declared common-mode
measurement nuisance. A burned reanalysis shows that these local contrasts are
live while a common scalar magnitude is incompatible with the observed
two-order ranges.

This is a principled successor object, not evidence from a prospective run.

## New boundary

The next physical experiment must not ask whether one absolute three-state
value transducer exists. It may ask:

```text
Which response contrasts are invariant to the declared measurement nuisance?

Which of those contrasts transport across display order and fresh contexts?

Does a common response operator exist, or is the maximal supported object a
context-indexed family?
```

Even positive answers concern an expressed response interface. They do not
identify moral value or close the reward-shaping theorem.
