# ASMP-9 decision-dependent evidence-ordering protocol v0.48

## Status and development disclosure

This protocol freezes a disjoint 12-outcome confirmation. The burned
development search used allocation `(1,1,1)`, ten declared grid/alpha cells,
and all 40,320 orderings. Four cells had disjoint decision-optimal ordering
sets. No development result may satisfy a confirmation gate.

The confirmation changes both the allocation and channel grid before any
confirmation decision risk or ordering outcome is computed.

## Frozen experiment

- Four latent targets and queries `(root,left,right)`.
- Horizon two and all 3,748 symbolic deterministic adaptive policies.
- Independent calibration counts with allocation `(2,1,1)`.
- Twelve complete error-count-vector outcomes:

  ```text
  {0,1,2} x {0,1} x {0,1}.
  ```

- Shared symmetric-flip parameter grid

  ```text
  {0,3/20,7/20}^3,
  ```

  containing 27 channels.
- `alpha=1/10`.
- Exact reference outcome law equal to the uniform mixture of the 27
  registered parameter laws.

The reference mixture is an optimization measure, not a claim about
deployment prevalence.

## Decision risks

1. `four_class_identification`: exact minimax zero-one risk of the complete
   horizon-two adaptive query experiment.
2. `root_group`: exact risk `d(p)=p_root`.

The statistical calibration experiment and reference law are identical
between the two objectives.

## Ordered confidence procedure

For a total ordering `pi=(x_1,...,x_12)` and prefix `S_j`, define

```text
U_pi(x_j)
  = max {d(p):P_p(S_j)>alpha}.
```

This is the smallest nondecreasing uniformly honest direct upper bound under
that ordering. Its registered cost is

```text
C_d(pi)=sum_x w(x)U_pi(x).
```

Exact subset dynamic programming exhausts the implicit `12! = 479,001,600`
ordering universe. It returns the minimum cost, optimizer count, and
lexicographically first optimizer.

## Frozen primary prediction

The complete optimizer sets for four-class and root-group loss are disjoint:

```text
argmin C_class
  intersect
argmin C_root
  = empty.
```

In addition:

```text
min_{pi root-optimal} C_class(pi)
  > min_pi C_class(pi),

min_{pi class-optimal} C_root(pi)
  > min_pi C_root(pi).
```

Both cross-regrets must be strictly positive. Different lexicographic
representatives without disjoint complete optimizer sets do not pass.

## Controls

1. `D0`: on the burned `{0,1/5,2/5}^3`, `alpha=1/10`,
   `(1,1,1)` fixture, the subset dynamic program must reproduce the exhaustive
   census exactly:

   ```text
   class optimum       = 1984/3125
   class optimizers    = 5040
   root optimum        = 246/625
   root optimizers     = 5040
   common optimizers   = 0
   class cross-regret  = 4/3125
   root cross-regret   = 2/625.
   ```

2. `C0`: the bound generated by each lexicographic optimizer has exact
   coverage at least `1-alpha` for every channel.
3. `A0`: for each decision loss, the singleton all-zero prefix bound equals
   the mandatory-atom maximum from v0.47. This is ordering independent when
   the all-zero atom is first.
4. Every experiment row and the reference mixture sum exactly to one.
5. Both subset-bound tables are nonconstant.

## Deterministic gates

| Gate | Requirement |
|---|---|
| `P0` | exactly 13 dedicated tests pass |
| `S0` | every registered source, protocol, theorem, prior-art, environment, runner, verifier, and inherited dependency hash matches |
| `U0` | exact 27-parameter, 12-outcome, `(2,1,1)`, `alpha=1/10` universe |
| `E0` | exactly 3,748 symbolic adaptive policies |
| `D0` | subset DP exactly reproduces all burned exhaustive-census values |
| `L0` | both risks and both subset-bound tables are nonconstant |
| `C0` | both reported optimal procedures have exact coverage at least `9/10` at all 27 channels |
| `A0` | both singleton all-zero bounds equal their direct mandatory-atom maxima |
| `X0` | optimizer intersection is empty and both cross-regrets are strictly positive |
| `RESOURCE` | wall time at most 180 seconds, aggregate working set at most 1 GiB, at most four risk workers |

`P0`, `S0`, `U0`, `E0`, `D0`, `L0`, `C0`, and `A0` are instrument-validity
gates. Failure returns `invalid_ordering_instrument`. A valid instrument with
failed `X0` returns `decision_dependent_ordering_not_established`. Only all
gates passing returns `decision_dependent_evidence_ordering_established`.

## Reproducibility

The runner writes:

- every exact parameter/outcome probability and decision risk;
- both complete 4,096-entry subset-bound tables;
- dynamic-program summaries and cross-audit;
- source, registration, test, and resource receipts; and
- an independent full replay.

Artifacts are compare-or-fail. The release manifest is built only after the
replay succeeds.

## Claim boundary

The result concerns one finite shared-BSC calibration experiment, one uniform
parameter-mixture objective, deterministic nondecreasing Buehler bounds, and
two finite decision risks. It does not prove that every preference-learning
problem lacks a universal statistic, optimize over reference laws, cover
randomized procedures or other confidence criteria, validate real preference
access, or resolve ASMP-9.
