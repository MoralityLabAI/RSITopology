# ASMP-9 resolution-obligation matrix after v0.78 development

## Verdict

**ASMP-9 remains unresolved.**

Version v0.78 proves that arbitrary finite deterministic minimum exact access
contains Set Cover with an optimum-preserving `+1` construction.

## Status against the five obligations

| Obligation | Strongest evidence after v0.78 | Status | Missing resolution evidence |
|---|---|---|---|
| 1. Maximal invariance or identifiability object | v0.74-v0.77 separate target fibers, licensed gauges, recovery, and leakage | **Exact for several finite classes** | Behavioral derivation across real data sources |
| 2. Necessary and sufficient access | Finite deterministic access is pair separation; v0.78 gives an exact Set Cover reduction | **General finite criterion plus worst-case hardness** | Structured natural channels, adaptive access, continuous classes, and physical acquisition |
| 3. Sharp query/sample/intervention bounds | Global exact minimum access is NP-hard for arbitrary finite registries; structured earlier cells remain tractable | **Computational obstruction established** | Approximation, parameterized algorithms, binary-only hardness, and general stochastic minimax rates |
| 4. Robustness to misspecification | v0.77 supplies one iid TV stress; v0.76 supplies a cross-cut taxonomy | **Restricted robustness results** | Drift, dependence, contamination, and strategic response |
| 5. No-go without a coherent latent value object | v0.71-v0.73 provide deterministic history replacements and finite-prefix limits | **One deterministic replacement branch** | Stochastic-kernel, relation-, set-, continuous-process-, and multi-agent replacements |

## Structural consequence

Any future claim of an efficient exact minimum-access rule must register the
structure that excludes the v0.78 Set Cover embedding. Otherwise the correct
deliverable is a certificate for one design, an approximation, or a
parameterized algorithm—not a universal closed form.

## Claim boundary

Version v0.78 is a finite worst-case reduction. It does not establish hardness
for human/model behavior or resolve ASMP-9.
