# ASMP-9 resolution-obligation matrix after v0.74 development

## Verdict

**ASMP-9 remains unresolved.**

Version v0.74 corrects the first canonical obligation. A maximal abstract
observation-invariance group is always available by permuting points within
observation fibers, but it need not be a physically licensed reward gauge.
The resolution target is equality between observation fibers and independently
licensed decision-gauge orbits.

## Corrected resolution grammar

```text
1. Freeze the decision problem and its licensed transformation grammar.
2. Derive the licensed orbit partition.
3. Derive the observation-fiber partition under registered access.
4. Require equality of the partitions.
5. Report underidentification or gauge-splitting witnesses otherwise.
```

## Claim boundary

Version v0.74 is elementary finite mathematics organized as a formulation
repair. It does not validate a shaping gauge, response model, intervention
channel, or latent human/model value object, and it does not resolve ASMP-9.
