# ASMP-9 resolution-obligation matrix after v0.66 development

## Verdict

**ASMP-9 remains unresolved.**

Version v0.66 closes another finite deterministic cell: when queries both
emit responses and update a known latent state, adaptive initial-state
identification with a terminal-distortion constraint is an exact least-fixed-
point problem.  This is classical automata state-identification machinery
specialized as an ASMP-9 access ledger, so the package remains unregistered.

The load-bearing uncertainty has moved from deterministic synthesis to
physical and misspecified dynamics.

## What v0.66 adds

### Initial versus current state

Every adaptive history carries a labelled belief of

```text
(initial state, current state)
```

pairs.  A query can reveal information and change the target in the same step.
Initial-state identification and terminal-state certainty are therefore
different properties.

### Exact terminal-disturbance fixed point

For a declared terminal distortion and budget, safe singleton beliefs seed a
least fixed point.  A belief is winning exactly when one query sends every
possible response branch to an already winning belief.  Iteration depth is the
minimum worst-case adaptive decision-tree depth.

### Three-way result

The complete two-state/two-query binary census contains:

```text
unidentifiable             64
identify_only_altering     40
identify_and_restore      152
```

A separate three-state fixture proves that pairwise distinguishability does
not imply one globally valid adaptive experiment.

### Reversible positive condition

If an ordinary identifying tree uses invertible transition words whose
inverses are available, append the inverse word at each leaf to restore the
initial state.  All 64 inverse-closed cells in the binary census satisfy the
implication.

## Registration decision

The [registration decision](dynamic_strategic_response_v0_66/REGISTRATION_DECISION_v0_66.md)
keeps v0.66 development-only.  Adaptive state identification is classical,
and another sealed finite table would not test whether elicitation changes a
real human or model target.

## Remaining load-bearing sequence

### A. Physical dynamic-response bridge

The next prospective protocol should test a real response system, not another
fully specified transducer.  Freeze:

1. a baseline target proxy measured on a disjoint instrument;
2. read-only, read-then-write, washout/restoration, and created-consensus
   control arms;
3. held-out query orders and contexts;
4. terminal and pathwise drift margins;
5. a downstream decision loss;
6. a stationary-transducer replay gate; and
7. a `latent_state_model_not_established` stop when that gate fails.

### B. Unknown and stochastic dynamics

Replace the known deterministic table by a registered uncertainty class over
transition/response kernels.  The target is robust adaptive
identify-and-restore, with matching indistinguishability witnesses when two
initial models produce overlapping transcript laws or when update uncertainty
absorbs the target difference.

### C. Structured hidden consideration

The v0.64 intermediate class remains open.  Declare restrictions on hidden
consideration, preference dependence, repeated latent sets, and observability;
then compute or bound separation without collapsing to unrestricted
singletons or verified exact pairs.

### D. General modulus computation or complexity

Extend the v0.63 exact capped-simplex result to a declared family of finite RUM
polytopes with exact dual certificates, or establish a sharp complexity
barrier for tier-modulus computation.

## Claim boundary

The suite does not establish that humans or models possess a coherent latent
value object, that the finite transducer is a valid behavioral model, that
terminal restoration prevents transient manipulation, that elicitation
preserves rather than constructs a target, or that the declared distortion has
moral meaning.  Version v0.66 is a development-level access ledger, not a
resolution of ASMP-9.
