# ASMP-9 v0.41 theorem draft: finite sequential access is a risk recursion

## Setup

Let the target set `Theta`, terminal action sets, query library, and every
query outcome alphabet be finite. Query `q` has rational channel
`P_q(y | theta)`. A policy may stop and choose a terminal action, or select a
query based on the complete preceding query/outcome history, through a frozen
finite horizon `h`.

For decision problem `d`, let `V_0(d)` contain the target-wise loss vector of
each terminal action. Recursively define:

```text
V_(h+1)(d,Q)
  = V_0(d)
    union over q in Q of
      { sum_y diag(P_q(y|.)) v_y :
        v_y in V_h(d,Q) for every outcome y }.
```

Let:

```text
U_h(d,Q) = conv(V_h(d,Q)) + R_+^Theta.
```

Coordinate-wise dominated generators may be removed at every step without
changing `U_h`.

## Theorem 1: adaptive Bellman risk-polytope recursion

`U_h(d,Q)` is exactly the upper risk set achievable by randomized adaptive
query policies using at most `h` queries followed by a terminal decision.

### Proof

At horizon zero, deterministic policies are precisely the terminal actions,
so their risk vectors are `V_0`. Randomization gives the convex hull and
worsening a risk coordinate gives the upper closure.

Assume the statement at horizon `h`. A deterministic nonterminal policy first
selects one query `q`. For each observed outcome `y`, it chooses an
outcome-specific continuation policy with risk generator `v_y`. Conditional
on target `theta`, the resulting risk is:

```text
sum_y P_q(y | theta) v_y(theta).
```

These are exactly the new generators in the recursion. The union over first
queries and the explicit terminal generators covers stopping. Randomization
over deterministic policy trees gives the convex hull. Induction completes
the proof.

## Corollary 1: necessary and sufficient finite sequential access

For a registered finite decision type `D`, adaptive library `A` is sufficient
relative to reference library `B`, horizon `h`, and tolerance `epsilon` iff:

```text
U_h(d,B) subset U_h(d,A) + epsilon*1
```

for every `d in D`.

Equivalently, it is enough to check every generator of `V_h(d,B)` against the
upper convex hull generated by `V_h(d,A)`. This is the sequential version of
the v0.40 upper-risk-polytope criterion.

## Corollary 2: deterministic identification is a decision tree

For deterministic finite queries and zero-one target identification, exact
adaptive access within horizon `h` exists iff there is a depth-at-most-`h`
decision tree whose leaves separate all targets.

The static zero-deficiency object from v0.40 is Test Cover. The sequential
zero-deficiency object is therefore an identifying decision tree. These
objects can have different costs.

## Strict adaptivity-gap witness

On four targets, use:

```text
root  = (0,0,1,1)
left  = (0,1,0,0)
right = (0,0,0,1).
```

The adaptive policy asks `root`, then asks `left` after outcome zero and
`right` after outcome one. It identifies every target in two queries.

No fixed sequence of two registered queries is injective. Exact nonadaptive
identification requires all three tests. Thus the v0.40 query-subset antichain
cannot characterize sequential access without policy-tree structure.

## Complexity boundary

The recurrence is exact but grows with the number of deterministic policy
trees. Optimal decision-tree construction is classically NP-hard. This
version therefore sharpens the finite object without supplying a generally
efficient algorithm.

## Claim boundary

Sequential experiment design, dynamic programming over information states,
and optimal decision-tree hardness are classical. The contribution claimed
here is an executable exact finite specialization that extends the ASMP-9
risk-polytope access object from static subsets to adaptive policy trees. It
does not establish finite-sample confidence validity, unknown-channel
robustness, strategic-demonstrator guarantees, or a real-model result.
