# ASMP-9 incomplete-menu access v0.55

This package distinguishes two questions that incomplete stochastic-choice
data often conflate:

1. does **some** Luce or random-utility completion exist; and
2. do the observed menus identify which full-kernel object tier is present?

The first question is classical revealed stochastic preference. The second is
the ASMP-9 access question studied here.

The development target is the full lattice of nonempty menu domains on three
alternatives. No representation-theorem novelty is claimed.
