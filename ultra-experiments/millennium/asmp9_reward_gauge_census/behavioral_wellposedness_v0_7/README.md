# ASMP-9 behavioral well-posedness v0.7

Development seed for the behavioral-access and inconsistent-demonstrator
branches of ASMP-9.

It separates three questions:

1. reconstructing a scalar value under a coherence promise;
2. testing whether the demonstrator admits such a scalar at all; and
3. approximating a continuous reward quotient from deterministic optimal-policy
   observations under environment interventions.

Run the development tests:

```powershell
python -m pytest `
  ultra-experiments/millennium/asmp9_reward_gauge_census/behavioral_wellposedness_v0_7/test_behavioral_access.py `
  -q
```
