# ASMP-9 v0.66 registration decision

## Decision

```text
do_not_register
```

Version v0.66 remains unregistered theorem development and is not
claim-eligible.

## Reason

The main mathematical object is a classical adaptive state-identification
experiment for a deterministic finite-state machine.  Initial-state
distinguishing experiments, final-state/homing experiments, incomplete
distinguishing sequences, and exact synthesis algorithms have a mature
literature beginning with Moore and Gill.

The terminal-distortion predicate is useful for the ASMP-9 access ledger, but
the current package does not establish that this combination is novel.
Prospectively sealing another finite replay would not test the load-bearing
uncertainty: whether an elicitation procedure changes a human or model value
state in practice, and whether any fitted transducer generalizes.

## Authorized use

The package may:

- update the ASMP-9 resolution-obligation matrix;
- define the distinction between discovery, destructive measurement, and
  constructed consensus;
- provide exact finite fixtures and a solver for protocol design; and
- define gates for a future physical bridge.

It may not be presented as:

- a novel automata or preference-elicitation theorem;
- a prospectively verified ASMP result;
- evidence that humans or models possess finite latent value states; or
- a resolution of ASMP-9.

## Registration-worthy successor

The next protocol should leave the finite transducer table unsealed and test a
real response system on held-out query orders.  It should prospectively freeze:

1. an initial-target proxy measured on a disjoint baseline instrument;
2. randomized read-only, read-then-write, and washout/restoration arms;
3. query-order holdouts capable of falsifying a stationary transducer;
4. a terminal and pathwise drift margin;
5. a created-consensus negative control;
6. a downstream decision loss; and
7. a stop rule that returns `latent_state_model_not_established` when
   transducer replay fails.

That bridge, not another exact two-state census, would address the remaining
scientific uncertainty.
