# Finite-sample tier certification requires a separation promise

Status: **candidate theorem; development only**.

## 1. Objects

Use the positive stochastic-choice kernels and bounded pairwise log-odds class
`BP_r(X)` from v0.57. Let

```text
Lbar = closure of the positive Luce kernels,
P    = the random-utility polytope.
```

Equip full kernels with the maximum menuwise `L1` metric

```text
d(p,q) = max_A sum_(x in A) |p(x|A)-q(x|A)|.
```

Write `d(p,C)=inf_(q in C)d(p,q)`.

## 2. No uniform finite-sample exact-tier classifier

### 2.1 Luce versus non-Luce RUM

Take three alternatives `a,b,c`. Let `p_0` be the uniform Luce kernel,
generated by the uniform distribution on the six strict rankings.

For `0<eta<1/6`, perturb the ranking weights in lexicographic order

```text
abc, acb, bac, bca, cab, cba
```

by

```text
eta * (0,-1,+1,-1,+1,0).
```

All pairwise choice probabilities remain `1/2`, while the full-menu vector is

```text
(1/3-eta, 1/3, 1/3+eta).
```

The kernel `p_eta` is RUM by construction and is not Luce for `eta>0`, because
uniform binary odds force equal Luce weights and hence a uniform full menu.
For `n=3`, every pair-context function has degree at most one, so both kernels
belong to `BP_1(X)`.

The two experiment laws differ only when the full menu is queried. The
single-draw divergence in the orientation used for Pinsker is

```text
D_KL(p_0(.|X) || p_eta(.|X))
  = -(1/3) log(1-9 eta^2).
```

For any adaptive procedure making at most `B` menu queries, the KL chain rule
gives total divergence at most

```text
-(B/3) log(1-9 eta^2).
```

Pinsker and Le Cam therefore imply

```text
max(error under p_0, error under p_eta)
  >= (1 - sqrt(KL_total/2))/2.
```

For every finite `B` and every target error `delta<1/2`, choose `eta` small
enough that the right side exceeds `delta`. No finite budget uniformly
distinguishes exact Luce from non-Luce RUM.

### 2.2 Non-Luce RUM versus non-RUM

The ranking mixture

```text
(abc,acb,bac,bca,cab,cba)
  -> (1/5,1/5,1/5,1/5,0,1/5)
```

induces a strictly positive choice kernel `q_0`. It is non-Luce and RUM. It
satisfies the regularity equality

```text
q_0(a|{a,b,c}) = q_0(a|{a,b}) = 2/5.
```

For any sufficiently small `epsilon>0`, leave all binary menus unchanged and
replace the full-menu vector by

```text
(2/5+epsilon, 2/5-epsilon, 1/5).
```

The resulting positive kernel `q_epsilon` violates regularity and is non-RUM.
It converges to `q_0` as `epsilon` tends to zero. The same two-point argument
shows that the RUM/non-RUM boundary also lacks a uniform finite-sample exact
classifier.

Together the paths show that the three exact tiers cannot be uniformly
classified at finite sample size, even under complete menu access.

### 2.3 A margin-promised lower bound

The second path also proves that the positive theorem below cannot improve its
dependence on the separation margin below quadratic order.

For the boundary kernel `q_0`, the binary Luce cycle identity has defect

```text
|p(a|ab)p(b|bc)p(c|ac)
 -p(b|ab)p(c|bc)p(a|ac)| = 6/125.
```

The difference of the two triple products is 6-Lipschitz in coordinate
`L-infinity` distance, which is bounded by maximum menuwise `L1`. It vanishes
on the Luce closure. Therefore

```text
d(q_0,Lbar) >= 1/125.
```

Fix `0<gamma<=1/125` and take `epsilon=2 gamma`. The perturbed kernel has a
regularity violation of `2 gamma`. The regularity functional is 2-Lipschitz in
the registered metric and is nonpositive on `P`, so

```text
d(q_(2 gamma),P) >= gamma.
```

Thus both hypotheses lie in `H_gamma`. Their only differing menu has

```text
D_KL(q_0(.|X) || q_(2 gamma)(.|X))
  = -(2/5) log(1-25 gamma^2).
```

Any adaptive classifier with maximum error at most `delta<1/2` therefore
requires at least

```text
B >=
  2(1-2 delta)^2
  / {-(2/5) log(1-25 gamma^2)}
```

menu queries. In particular `B=Omega(gamma^-2)`. This is a matching margin
exponent on the three-alternative `BP_1` slice, not a general minimax constant.

## 3. A non-discretionary separation promise

Fix `gamma in (0,2]`. Restrict the true kernel to the union

```text
H_gamma =
    L
  union {p in P\Lbar : d(p,Lbar) >= gamma}
  union {p notin P   : d(p,P)    >= gamma}.
```

This is a promise about distance from ambiguous boundaries, not an assumption
that one particular tier is true.

Given an estimated full kernel `p_hat`, define

```text
if d(p_hat,P) > gamma/2:
    return N
if d(p_hat,P) = gamma/2 or d(p_hat,Lbar) = gamma/2:
    return inconclusive
if d(p_hat,Lbar) < gamma/2:
    return L
return R
```

If `d(p_hat,p)<=gamma/3`, this rule returns the true tier for every
`p in H_gamma`. The proof is the triangle inequality:

- true `L`: distance to both sets is at most `gamma/3`;
- true `R`: distance to `P` is at most `gamma/3`, while distance to `Lbar` is
  at least `2gamma/3`;
- true `N`: distance to `P` is at least `2gamma/3`.

The equality state is explicit rather than adjudicated after observing data.

### Computational access to the distances

The statement is information-theoretic, but the two distance objects are
well-defined finite computations.

- Distance to `P` is a linear program over the simplex of `n!` strict-ranking
  weights, with absolute residuals linearized menu by menu.
- The normalized positive Luce family is semialgebraic after clearing its
  positive menu denominators. Its closure is compact and semialgebraic.
  Distance to `Lbar` is therefore decidable for fixed finite `n` in the
  real-closed-field model, for example by quantifier elimination.

No polynomial-time algorithm or practical exact Luce-distance implementation
is claimed. Replacing either distance by a numerical approximation requires
registered upper and lower certificates around the `gamma/2` thresholds.

## 4. Finite-sample sufficient bound

Observe `N` iid choices independently from every menu in

```text
D_(r+2) = {A: 2<=|A|<=r+2}.
```

Assume every observed choice probability is at least `a>0`. Let

```text
Q(n,r) = sum_(k=2)^(r+2) k choose(n,k)
```

be the number of observed probability coordinates.

For the v0.57 interpolation norm, define

```text
K(s,r)
  = 1                                           if s<=r,
  = sum_(u=0)^r choose(s,u)choose(s-u-1,r-u)   if s>r,

K_star(n,r) = max_(0<=s<=n-2) K(s,r).
```

Suppose every observed empirical coordinate differs from truth by at most
`t<a`. Then every observed pairwise log odds differs by at most

```text
epsilon(t,a) = -2 log(1-t/a).
```

Mobius reconstruction gives target root-log-odds error at most

```text
E = K_star(n,r) epsilon(t,a).
```

Normalizing the reconstructed root ratios does not change the range of their
log likelihood-ratio errors. That range is at most `2E`. The sharp
likelihood-ratio oscillation bound

```text
TV(p_hat(.|A),p(.|A))
  <= tanh[(max log L - min log L)/4]
```

therefore yields

```text
d(p_hat,p)
  <= 2 tanh(E/2)
  = 2 tanh[-K_star(n,r) log(1-t/a)].
```

Set

```text
t_gamma
  = a * {
      1 - exp[
        -atanh(gamma/6) / K_star(n,r)
      ]
    }.
```

Then coordinate error at most `t_gamma` implies
`d(p_hat,p)<=gamma/3`.

Coordinatewise Hoeffding and a union bound give the sufficient per-menu count

```text
N >= log(2 Q(n,r)/delta) / (2 t_gamma^2).
```

With probability at least `1-delta`, the reconstructed kernel is within
`gamma/3` and the margin-promised classifier returns the true tier.
Empirical zeros or exact threshold equalities return `inconclusive`.

For small `gamma`,

```text
N = O(
  K_star(n,r)^2
  / (a^2 gamma^2)
  * log(Q(n,r)/delta)
).
```

This is an explicit sufficient rate, not a minimax constant.

The lower bound in Section 2.3 shows that the `gamma^-2` dependence cannot be
improved uniformly even at `n=3,r=1`. It does not match the upper bound's
dependence on `n`, `a`, `K_star`, or `delta`.

## 5. What the theorem changes

Version v0.56 showed that unrestricted missing-menu completion destroys tier
identification. Version v0.57 supplies a structured exact recovery class.
Version v0.58 identifies the statistical price and the unavoidable boundary:

```text
structural completion is not enough;
finite-sample exact tiers also require separation.
```

## Claim boundary

This theorem is conditional on iid samples, known `r`, known probability floor
`a`, a fixed nested menu design, and a declared separation promise. It does not
select the structural model, give an efficient Luce-distance algorithm, prove
minimax constants, handle strategic or nonstationary demonstrators, or attach
welfare meaning to the recovered tier. ASMP-9 remains unresolved.
