# General-graph informative-fiber allocation: formulation draft

## Frozen ancestor

For an oriented graph with edge counts `Y`, capacities `N`, and incidence
matrix `D`, ASMP-9 v0.13 conditions on

```text
D^T Y = t.
```

The resulting fiber is

```text
F_t = {y : 0 <= y_e <= N_e, D^T y=t}.
```

Its affine difference span `S_t` is the reward-quotient subspace visible to
the conditional experiment. The full quotient is available exactly when

```text
dim(S_t) = beta_1(G).
```

Version v0.16 solved fixed-total allocation only when `G` is one cycle.

## Residual-network liveness theorem target

For any realized count vector `y`, form a directed residual graph:

- include the registered forward orientation of edge `e` when `y_e<N_e`;
- include the reverse orientation when `y_e>0`.

Thus each edge has one of only three relevant statuses:

```text
Z: y_e=0       -> forward residual arc only
I: 0<y_e<N_e   -> both residual arcs
F: y_e=N_e     -> reverse residual arc only.
```

Let `H_y` contain precisely the original edges whose endpoints lie in one
strongly connected component of the residual digraph. Equivalently, these
are the edges whose available residual arc lies on a directed residual
cycle.

The development theorem is:

```text
dim(S_t) = beta_1(H_y).
```

Consequently:

```text
dim(S_t)=beta_1(G)
iff every non-bridge edge of G lies on a directed residual cycle.
```

This would convert full-quotient availability from enumeration of every
binomial count into a `3^|E|` exact status calculation.

Proof route: feasible differences from `y` are precisely circulations in the
residual network. Flow decomposition writes the residual circulation cone as
the conic hull of directed cycles, so its linear span is generated by those
cycles. Delete residual arcs not lying in a strongly connected component and
map each remaining arc back to its signed original edge. If `d` original
edges are bidirected, the residual directed cycle space has dimension

```text
|E(H_y)| + d - |V(H_y)| + c(H_y),
```

while the arc-to-edge map has exactly the `d` independent two-cycle kernels.
Its image therefore has dimension `beta_1(H_y)`.

This proof must be written formally and checked against direct fiber
enumeration before registration.

## Exact unconditional objective

For edge `e`, trial count `n_e`, and win probability `p_e`, define:

```text
P_e(Z) = (1-p_e)^n_e
P_e(F) = p_e^n_e
P_e(I) = 1-P_e(Z)-P_e(F).
```

For status vector `sigma`, let `L_G(sigma)` be one when the residual
criterion has full cycle rank and zero otherwise. Then:

```text
A_G(n,p)
  = sum_sigma L_G(sigma) product_e P_e(sigma_e).
```

Under the symmetric interior:

```text
epsilon <= p_e <= 1-epsilon,
```

endpoint restriction is in fact available beyond one cycle. With every other
edge frozen, liveness is monotone when a boundary status `Z` or `F` is
replaced by `I`. Therefore the probability as a function of one `p_e` has
the form

```text
c - a(1-p_e)^n_e - b p_e^n_e,  a,b >= 0,
```

which is concave. Iterating coordinatewise shows that a minimum over the
probability box occurs at an endpoint assignment. Define:

```text
F_G(n,epsilon)
  = min over p_e in {epsilon,1-epsilon} A_G(n,p).
```

For fixed total `N`, the design problem is:

```text
maximize F_G(n,epsilon)
subject to n_e positive integers and sum_e n_e=N.
```

The endpoint reduction needs an explicit formal lemma in the theorem packet,
but it does not require a new empirical assumption.

## Live alternatives

The first exact search must distinguish:

1. **uniform survives:** counts differing by at most one are maximin on every
   registered bridgeless graph;
2. **cycle-block allocation:** total count first balances across
   2-edge-connected blocks, then within each block;
3. **cycle-participation allocation:** edges receive count according to
   leverage, effective resistance, spanning-tree inclusion, or a related
   cycle-matroid weight; and
4. **no scalar rule:** optimal allocation depends on the full oriented
   residual reliability polynomial.

Any counterexample to uniform allocation is valuable because it prevents the
single-cycle theorem from being transferred to realistic overlapping-cycle
designs.

## Claim boundary

This is a development formulation, not a theorem or protocol. It assumes
independent fixed-count Bernoulli comparisons, observed graph identities, a
known symmetric probability interior, and endpoint-restricted nuisance
probabilities. It does not address adaptive allocation, response dependence,
unknown links, behavioral validity, general inverse reinforcement learning,
or ASMP-9 resolution.
