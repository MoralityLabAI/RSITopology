# ASMP-9 v0.43 theorem draft: the regular finite-horizon rate is linear

## 1. Why v0.43 exists

Version v0.42.1 first constructed a simultaneous per-query total-variation
radius `eta`, then bounded every horizon-`h` transcript by `h eta`. With
`eta = O(n^(-1/2))`, this gives a sufficient sample floor

```text
n = O(h^2 / g^2)
```

for a deficiency gap `g`. The v0.42 resolution matrix left two possibilities:
the factor might be necessary, or it might be an artifact of applying a
worst-case TV union bound before using the sequential experiment's geometry.

Version v0.43 establishes the second possibility on an exact sentinel family
and identifies the corrected rate.

## 2. General KL-regular perturbation theorem

Fix a target `theta`, a horizon `h`, and a possibly randomized,
history-adaptive query policy `pi`. Let `P_pi` and `P_hat_pi` be the two
transcript laws generated by the same policy under two channel libraries.
Suppose every query cell satisfies the directed conditional bound

```text
KL(P(. | theta,q) || P_hat(. | theta,q)) <= kappa(theta).
```

The chain rule gives

```text
KL(P_pi || P_hat_pi)
  = sum_{t=1}^h
      E_P [
        KL(
          P(. | theta,q_t(H_{t-1}))
          ||
          P_hat(. | theta,q_t(H_{t-1}))
        )
      ]
  <= h kappa(theta).
```

The query chosen after a realized history is the same measurable policy
function in both conditional laws, so adaptivity introduces no additional KL
term. Pinsker and the variational characterization of bounded expectations
then imply, for a terminal loss with span `s(theta)`,

```text
|R_pi(theta) - R_hat_pi(theta)|
  <= s(theta) min(1, sqrt(h kappa(theta) / 2)).
```

This bound is uniform over all policy trees.

### Corollary: the proposed quadratic-KL witness cannot exist

Suppose a two-point channel path is parameterized by `delta` and every
one-step cell obeys

```text
KL(P_delta || P_0) <= C delta^2.
```

For unit-span loss, every horizon-`h` policy obeys

```text
risk_gap / (h delta) <= sqrt(C / (2h)).
```

The right side tends to zero. Therefore no KL-regular family can produce a
uniform `Omega(h delta)` bounded-loss risk gap while retaining
`O(delta^2)` one-step KL as `h` grows. The first proposed lower-bound shape in
the v0.42 matrix was internally incompatible with the transcript chain rule.

This does not say `h eta` is never attained in TV. Boundary-support
perturbations attain `1-(1-eta)^h`, which is first-order `h eta`; those paths
do not have the same regular quadratic KL geometry.

## 3. Exact sentinel experiment

There are two targets `theta in {0,1}`, binary observations, zero-one terminal
classification loss, and one query usable at most `h` times:

```text
P(Y=1 | theta=0) = 0
P(Y=1 | theta=1) = p.
```

The only ambiguous transcript is `0^h`. Under target one its probability is

```text
a_h(p) = (1-p)^h.
```

On any transcript containing a one, target one is known exactly. On `0^h`,
let the decision rule output target one with probability `r`. The two
target-wise risks are

```text
R_0(r) = r
R_1(r) = a_h(p) (1-r).
```

The directed deficiency to perfect revelation is their smallest common upper
bound. Equalizing them gives the exact formula

```text
D_h(p) = a_h(p) / (1 + a_h(p)).
```

Its derivative magnitude is

```text
|D_h'(p)|
  = h (1-p)^(h-1) / (1 + (1-p)^h)^2.
```

At probabilities of order `1/h`, the derivative is of order `h`; the
decision boundary is genuinely horizon-sensitive.

## 4. Matching two-point lower rate

For `h >= 2` and `0 < epsilon <= 1/4`, define

```text
p0 = 1/(2h)
p1 = (1/2 + epsilon)/h.
```

On the interval between them:

```text
|D_h'(p)| >= h/16.
```

The denominator in the derivative is at most four. Bernoulli's inequality
gives

```text
(1-p)^(h-1)
  >= 1 - (h-1) 3/(4h)
  > 1/4.
```

Hence the exact deficiency gap `g_h(epsilon)` obeys

```text
epsilon/16 <= g_h(epsilon) <= epsilon.
```

For the iid channel samples,

```text
KL(Ber(p0) || Ber(p1))
  <= chi2(Ber(p0) || Ber(p1))
  = (p1-p0)^2 / (p1(1-p1))
  <= 4 epsilon^2 / h.
```

Any access classifier that has error at most `1/4` at both points induces a
test with total error at most `1/2`. Pinsker therefore requires

```text
n KL >= 1/2.
```

Consequently:

```text
n >= h / (8 epsilon^2)
  >= h / (2048 g_h(epsilon)^2).
```

The constants are deliberately elementary rather than optimized. The
load-bearing statement is:

```text
n = Omega(h / g^2).
```

## 5. Matching block upper rate

Partition `n` iid samples from the target-one channel into

```text
m = floor(n/h)
```

disjoint blocks of length `h`. For each block, record whether every outcome
is zero. These indicators are iid Bernoulli with mean `a_h(p)`. Hoeffding
gives:

```text
|a_hat - a_h(p)|
  <= sqrt(log(2/alpha)/(2m))
```

with probability at least `1-alpha`. The map `a -> a/(1+a)` has derivative
at most one on `[0,1]`, so the same radius covers `D_h(p)`. A strict radius
below `g` requires:

```text
m > log(2/alpha)/(2g^2)
n = O(h log(1/alpha)/g^2).
```

Together with the two-point witness, the sentinel family's horizon and gap
exponents are sharp:

```text
n = Theta(h / g^2)
```

at fixed confidence.

## 6. Scope

The result:

- proves a policy-uniform KL perturbation bound for finite adaptive query
  trees;
- rejects the proposed `h delta` plus quadratic-KL witness;
- gives an exact binary deficiency formula;
- establishes matching `h/g^2` exponents on that sentinel family; and
- shows that v0.42.1's `h^2/g^2` sufficient rate is not intrinsic there.

It does not:

- give a minimax rate over every finite adaptive experiment;
- construct optimal simultaneous KL confidence regions for arbitrary
  multinomials;
- make exact policy compilation polynomial;
- cover unbounded horizons, strategic sources, misspecified demonstrators, or
  continuous channels; or
- resolve ASMP-9.
