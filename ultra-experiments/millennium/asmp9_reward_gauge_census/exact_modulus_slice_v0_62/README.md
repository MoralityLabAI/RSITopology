# ASMP-9 exact modulus slice v0.62

This unregistered development lane computes the two class moduli introduced in
v0.59 and v0.60 on one continuous, compact, nontrivial stochastic-choice
slice.

The slice has three alternatives, fixed non-Luce binary menus, a compact
non-Luce RUM segment, and a compact non-RUM segment separated by the v0.58
kernel margin.  It admits exact primal witnesses and elementary dual lower
certificates:

```text
Delta  = gamma,
Lambda = 1 + (5/2) gamma.
```

The result is a deliberately solvable calibration cell, not a general modulus
algorithm and not an ASMP-9 resolution.  All current outputs are development
only and burned before any prospective successor.
