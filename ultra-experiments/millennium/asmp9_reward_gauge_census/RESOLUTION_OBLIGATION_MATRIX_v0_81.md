# ASMP-9 resolution-obligation matrix after v0.81

## Verdict

**ASMP-9 remains unresolved.**

The first controlled acquisition failure has now been repaired inside the same
synthetic response channel by a prospectively registered decoder that uses
known physical intervention offsets. This is a positive access result, not a
natural-value result.

| 1. Maximal invariance or identifiability object | Controlled potential-shaping targets and exact non-gauge offsets were independently verified | **Exact inside one synthetic finite MDP** | Natural behavioral or moral target/gauge licensing; broader target classes |

| 5. No-go without a coherent latent value object | v0.71-v0.73 deterministic replacement branch unchanged | **One deterministic replacement branch** | Stochastic-kernel, relation-, set-, continuous-process-, and multi-agent replacements |

## Program consequence

The controlled finite-MDP branch has served its purpose: it demonstrated both
a valid decoder failure and a preregistered structural repair. Another seed in
the same known-offset softmax fixture is not load-bearing.

The next admissible physical branch must test whether the decoder structure is
available rather than assumed—e.g. whether intervention offsets can be
calibrated on construction contexts and transported to disjoint contexts in a
real response channel. Alternatively, a theorem branch must supply a sharp
minimax access bound for the structured experiment. Threshold retuning or a
larger synthetic registry alone does not advance the resolution obligation.

## Claim boundary

Version v0.81 establishes one controlled constructive sufficiency example and
one matched decoder comparison. It does not identify human/model values or
resolve ASMP-9.
