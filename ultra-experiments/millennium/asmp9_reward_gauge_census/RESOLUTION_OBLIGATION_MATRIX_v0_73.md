# ASMP-9 resolution-obligation matrix after v0.73 development

## Verdict

**ASMP-9 remains unresolved.**

Version v0.73 identifies the open-ended future-increment quotient behind the
bounded v0.71 history replacement. It proves a conditional finite
distinguishing horizon inside a declared finite-state class and an
unconditional finite-prefix obstruction when no such bound is registered.

## Status against the five obligations

| Obligation | Strongest evidence after v0.73 | Status | Missing resolution evidence |
|---|---|---|---|
| 1. Maximal invariance or identifiability object | The future-increment Myhill-Nerode quotient is the canonical minimal deterministic history object | **Exact for deterministic additive histories** | Stochastic, continuous, relational, strategic, multi-agent, and semantically grounded objects |
| 2. Necessary and sufficient access | Finite index is necessary and sufficient for a finite deterministic reward machine; a declared `K`-state class has a `K-1` internal refinement horizon | **Exact conditional access theorem** | Independent justification of `K`, noisy/adaptive acquisition, partial alphabets, and physical access |

| 4. Robustness to misspecification | Delayed-pulse controls expose finite-prefix overclaim and growing hidden memory | **One exact temporal misspecification family** | Drift, dependence, hidden context, contamination, strategic response, and nonstationary stochastic processes |
| 5. No-go without a coherent latent value object | Infinite future-increment equivalence supplies the replacement; finite prefixes cannot certify its finite stabilization without a bound | **Deterministic history branch sharpened** | Relation-, kernel-, set-, continuous-process-, and multi-agent replacement classes |

## New decision rule

```text
If a state/regularity bound is registered independently:
    report identification relative to that class.

If no such bound is registered:
    do not infer open-ended stationarity or finite memory from prefix
    stabilization.
```
