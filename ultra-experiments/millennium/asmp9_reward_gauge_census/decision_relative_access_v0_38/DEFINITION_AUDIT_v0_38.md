# ASMP-9 v0.38 definition audit: decision-relative access

## Status

`development_definition_pinned_not_registered`

This file fixes the mathematical meaning of the v0.38 instrument before any
confirmation registry is chosen.

## Primary-source alignment

Torgersen defines comparison rule by rule: for every decision problem and
every rule in a reference experiment, the more informative experiment must
have a rule that is no riskier at every parameter value. He then explicitly
restricts this comparison to declared *types* of decision problems, obtaining
relative deficiencies and distances:

- Erik Torgersen, *Comparison of Statistical Experiments*, Chapter 6,
  “Deficiencies”:
  <https://doi.org/10.1017/CBO9780511666353.007>.

Goel and DeGroot treat a target parameter with nuisance by fixing a joint
prior, integrating the conditional nuisance law into the target-indexed
experiment, and considering losses that depend only on the target:

- Prem K. Goel and Morris H. DeGroot, “Comparison of Experiments and
  Information Measures,” *Annals of Statistics* 7(5), 1979:
  <https://doi.org/10.1214/aos/1176344790>.
- Author-hosted technical-report scan, especially equation (5.1) and the
  following definition:
  <https://www.stat.purdue.edu/docs/research/tech-reports/1-527/tr-484.pdf>.

Version v0.38 uses the finite, pointwise target-risk specialization below. It
does not claim a new comparison theorem.

## Registered nuisance semantics

Let `theta in Theta` be the reward/decision class and `xi in Xi` the declared
nuisance. An expanded experiment has rational rows

```text
E(y | theta, xi).
```

A frozen conditional nuisance law `kappa(xi | theta)` defines the marginal
target experiment

```text
E_bar(y | theta)
  = sum_xi kappa(xi | theta) E(y | theta, xi).
```

The conditional law is part of the experiment. It may encode dependence
between target and nuisance. Changing it changes the result and requires a
new registration. The v0.38 instrument is not a robust guarantee over unknown
nuisance laws.

For comparison, the expanded-parameter instrument keeps `(theta, xi)` as the
parameter and does not marginalize. Both quantities are reported.

## Registered decision type

Each decision problem `d` has:

- a finite policy/action set `A_d`;
- a loss matrix `L_d(theta, a)` with every entry in `[0, 1]`; and
- no direct dependence on `xi`.

For a randomized rule `sigma(a | y)` in experiment `E_bar`, its target-risk
vector is

```text
R_E_bar(theta, sigma; d)
  = sum_y sum_a E_bar(y | theta) sigma(a | y) L_d(theta, a).
```

The initial specialization uses policy regret generated by a frozen finite
reward registry and frozen policy occupancy vectors. Constant reward shifts
are a licensed gauge because they leave every policy-regret row unchanged.

## Definition implemented

For a finite registered decision type `D`, the directional relative
deficiency of source access `E` with respect to reference access `F` is

```text
delta_D(E, F)
  = inf { epsilon >= 0 :
      for every d in D,
      for every rule tau in Rules(F),
      there exists sigma in Rules(E) such that
      for every theta in Theta,
      R_E(theta, sigma; d)
        <= R_F(theta, tau; d) + epsilon }.
```

This is not the optimized value gap

```text
G_D(E, F)
  = sup_d [V_E(d) - V_F(d)]_+.
```

`G_D` compares one optimized value per problem. `delta_D` transfers every
reference rule's entire risk vector.

Ordinary expanded-parameter deficiency is separately defined by

```text
delta_full(E, F)
  = inf_K sup_(theta, xi)
      TV(F_(theta,xi), K E_(theta,xi)),
```

where `K` is one Markov kernel. It can charge nuisance distinctions that the
target-only decision type does not use.

## Exact finite reduction

For one reference rule `tau`, v0.38 solves the rational linear program

```text
minimize epsilon

subject to
  R_E(theta, sigma; d)
    <= R_F(theta, tau; d) + epsilon  for every theta,
  sigma(. | y) is a probability distribution for every y,
  epsilon >= 0.
```

It then maximizes the exact optimum over decision problems and deterministic
reference rules.

Deterministic reference rules suffice. The source experiment's randomized
risk vectors form a convex polytope; its componentwise upper closure is
convex. The minimum additive shift needed to enter that upper set is a convex
function of the reference risk vector. A convex function on the reference
risk polytope attains its maximum at an extreme point, and every extreme risk
vector is the image of at least one deterministic reference rule.

The floating LP is used only to propose a full-rank active set. The accepted
answer is reconstructed over `Fraction`, checked against every constraint,
and accompanied by an exact nonnegative dual whose value equals the primal
value. Floating output cannot become a certificate.

## Normalization and direction

- Every registered loss lies in `[0,1]`, so `epsilon` is an additive risk
  relaxation in those units.
- `delta_D(E,F)` asks how much is lost by using `E` in place of `F`.
- Passing at tolerance `epsilon_0` means
  `delta_D(E,F) <= epsilon_0`; equality passes only if frozen that way.
- Deficiency is directional. Reverse values are not inferred.

## Claim boundary

This audit fixes one classical finite instrument and one nuisance semantics.
It does not establish that a fixed nuisance law is scientifically adequate,
that the finite policy registry captures human values, that target-relative
deficiency always has a channel-simulation form, or that ASMP-9 is resolved.
