## Rules

- A *package* is any directory holding a `RESULT*`, `PUBLIC_SUMMARY*`,
  `DEVELOPMENT_RESULT*`, `RESOLUTION_DISPOSITION*`, `REASSESSMENT*` or
  `*PRIOR_ART*` markdown file. Versioned subpackages without their own
  prior-art file inherit the parent's (marked).
- *Status*: the first long backticked token in the first 25 lines of the
  package's latest result file, else the first paragraph under a verdict-like
  heading, else the first body paragraph.
- *Novelty sentence* / *external description*: the first blockquote or
  paragraph under a heading mentioning a novelty sentence / an external
  description in the latest prior-art file. These are the two sentences
  `PRIOR_ART_BEFORE_FREEZE_STANDARD_v0_1.md` requires.
- *Verdict*: first paragraph under a verdict/decision/disposition heading of
  the prior-art file; *tokens*: backticked disposition tokens found there.
- *Novelty mentions*: every sentence containing "novel" or "candidate-new" in
  result, prior-art, theorem and note files, with markdown emphasis removed
  and headings kept apart. A sentence `disclaims` if it contains a negation
  word (not, no, neither, never, without, unestablished, reject, forbid,
  cannot, insufficient, absent, withdrawn); otherwise it `asserts_or_hedges`.
  Only the second kind is listed; the rule errs toward listing.
