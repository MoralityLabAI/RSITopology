# Reviewer packet v0.21

## Claim to attack

Equality of active event-support incidence defines the coarsest quotient that
preserves the full finite support relation up to duplicate labels. This
quotient preserves feasibility and is invariant under raw renaming and v0.20
cloning.

## Highest-value falsification attempts

1. Find two identical signatures that induce different current `q` witnesses
   or successor beliefs from some reachable observer state.
2. Find two distinct signatures that can be merged while still reconstructing
   both original active incidence classes.
3. Find a raw renaming or duplicate clone that changes the quotient observer
   language or spectral radius.
4. Contradict the independent row-support/column-signature joint census.
5. Find a feasible deterministic relation with two distinct active labels that
   have the same incidence signature.

## Scope check

A valid falsification must target exact support preservation. Showing that a
coarser statistic suffices for control would motivate a successor minimal-
control quotient; it would not contradict this theorem's narrower canonical
object.
