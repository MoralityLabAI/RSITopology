# ASMP-11 v0.2.1.1 serialization repair

## Status

Operational source repair only. This note authorizes no registration, claim
run, or reuse of the existing v0.2.1 artifact attempt.

The first Windows execution completed scientifically and passed the independent
checks on its original bytes. However, three hash-bound JSON writers used
`Path.write_text` without an explicit newline policy. Windows emitted CRLF,
while the repository's `eol=lf` rule would normalize those files during
staging. The recorded SHA-256 values would therefore describe different bytes
from the committed artifacts. The attempt is preserved in place but is not a
byte-integrity-valid release.

## Repair

Every owned writer was audited:

| Writer | Prior state | v0.2.1.1 state |
|---|---|---|
| `run.py::atomic_json` | platform newline translation | shared LF-only text helper |
| `run.py::write_jsonl` | already opened with `newline="\n"` | unchanged and regression-tested |
| `build_registration.py` registration writer | platform newline translation | LF-only text helper |
| `verify_result.py` verification-receipt writer | platform newline translation | LF-only text helper |
| `verify_result.py` JSONL reader | read-only | no change required |

The helpers call `Path.write_text(..., encoding="utf-8", newline="\n")`.
Regression tests inspect generated bytes directly, require a terminal LF, and
reject every CRLF occurrence for pretty JSON, atomic JSON, registration-style
text, verification-style text, and JSONL.

No mathematical object, grid, resource ceiling, cost rule, classification,
metric probe, claim boundary, or prior anchor changed.

## Required sequence

1. Commit this source repair separately.
2. Build and commit a new prospective registration bound to that repair commit.
3. Execute into a new non-aliasing artifact directory.
4. Verify the new artifacts and confirm their hashes remain unchanged after
   the repository's LF policy is applied.

The existing `RESULT_v0_2_1.md` and `artifacts_v0_2_1/` remain preserved as the
superseded Windows serialization attempt until the registered repair is run.
