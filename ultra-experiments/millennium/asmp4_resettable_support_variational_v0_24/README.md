# ASMP-4 resettable support-functional theorem v0.24

This package replaces two isolated port thresholds with a weighted family that
recovers the complete closed convex region generated by reset-concatenable safe
blocks. It freezes a parameterized architecture schema, proves the abstract
support theorem, recovers prior rectangular and nonrectangular examples, and
states the block-completeness condition needed before applying the formula to
the full infinite-horizon region.

Run the central harness:

```powershell
python run_verification.py
```

Run the import-independent verifier:

```powershell
python verify_resettable_support_variational.py
```

Run focused tests:

```powershell
python -m pytest -q test_resettable_support_variational.py
```

The frozen architecture fields and claim are `architecture_schema_v0_24.json`
and `resettable_support_claim_v0_24.json`.

The v0.25 successor proves periodic completeness for finite public additive
scheduler state. It also shows that irreversible recurrent-component forks
require a disjunction of component support families rather than one globally
convexified support family.
