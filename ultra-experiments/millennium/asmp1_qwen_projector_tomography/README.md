# ASMP-1 real-model projector tomography

This preregistered Qwen-0.8B experiment applies the interaction-order tomography instrument to four lineage-certified, rank-one graph-reachability projectors at layers 11, 15, 19, and 23.

The intervention is the sign-invariant projector `v v^T`, not a signed transported coordinate. All 16 binary subsets are evaluated on 72 held-out graph prompts for the selected projectors and seeded orthogonal matched-random controls. The primary test is leave-one-subcondition-out improvement from degree-two terms over an additive model.

The generated `registration.json` seals source data, projectors, prompts, code, environment, and the exact capped command before causal outcomes exist. Results remain engineering evidence and do not authorize VPD weight edits.
