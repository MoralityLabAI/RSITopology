# Reviewer packet v0.20

## Claim to attack

Cloning every raw output into `m` irrelevant colors leaves feasibility and
writes invariant but multiplies observer adjacency and language growth by `m`.
Consequently a plant-only forced-raw read entropy is not canonical without a
sensor selector or quotient rule.

## Highest-value falsification attempts

1. Find a colored event whose successor belief or current `q` set differs from
   its base event under the registered construction.
2. Find a base word with a number of supported colorings other than `m^T`.
3. Show that a color changes a v0.13 write lower bound or supplies actuator
   information not already present in `q`.
4. Find a clone in the 768-instance census whose feasibility differs from its
   base table.
5. Show that `pi(y,j)=y` fails to reconstruct the base support relation.

## Scope check

A valid review must distinguish the stopped plant-only forced-raw claim from a
parameterized sensor theorem or an encoder-optimized capacity region. Refuting
the scoped stop requires restoring a single plant-only value across the clone
family without silently changing the read registration.
