# ASMP-4 semantic selector audit v0.15

## Frozen question

Does a clause-complete conservative audit support the v0.14 assertion that the canonical ASMP-4 text contains no semantic selector between the computed `q`-fiber sensor and the forced raw-mode-injective sensor?

The preregistered rule is hostile: every canonical clause must be covered exactly once, and any `ambiguous`, `selects_computed`, `selects_raw`, or `selects_parameterized` label blocks support. Exact-string absence is only a baseline.

## Metric robustness

The deterministic selector-risk metric passed all five staged held-out probe families: invariance, sensitivity, monotonicity, anti-gaming, and clean control. The fixture file was SHA-256 sealed before observations, and its hash is embedded in every staged source reference. This supports only the local metric behavior on those declared probes.

## Task result

The complete source census contains 23 units: 15 no-selector units, seven ambiguous units, and one parameterized-selector unit. The eight blockers are `C03`, `C04`, `C06`, `C07`, `C08`, `C11`, `C19`, and `C22`.

The most important findings are:

- `C07` permits evaluator-tangent quotienting but does not say whether this mandates sensor coarsening or only constrains the entropy invariant.
- `C08` asks for a registered class but does not enumerate whether the sensor experiment belongs to that class grammar.
- `C11` requires coordinate-invariant transversal entropies without defining which sensor refinements count as coordinate artifacts.
- `C19` explicitly says to hold the sensor experiment fixed in the split-port witness. That treats the experiment as registered instance data and is incompatible with claiming that parameterization is wholly absent.

Therefore the declared semantic no-selector claim is rejected under its frozen decision rule.

## Measurement reliability

The generic base-policy pairwise preflight failed and remains release-blocking. The source is a fixed 23-unit complete population, not a held-out sample; no subjective comparison is blinded, randomized, or position-swapped; and padding the population to the policy minimum would be pseudo-replication. Contamination and deterministic-schema omissions were repaired before outcomes, but the adapter mismatch was preserved rather than hidden.

This failure does not erase the deterministic source census. It does prevent treating the package as a publication-style calibrated pairwise evaluation or generalizing its labels beyond this frozen document without external adjudication.

## Claim support

Rejected. Lexical absence of six phrases does not establish semantic absence. V0.14's exact positive-volume fork remains valid, but its inference to a proved source-level semantic underdetermination requires qualification.

## Operational decision

Retain the stop on producing more favorable local fixtures, but revise its rationale. The canonical source may intentionally call for a parameterized theorem over registered sensor experiments. This repository has proved exact conditional regions for several registrations; it has not proved the requested global variational theorem or that the source must select one numeric region.

The next legitimate moves are clause-level external adjudication, a canonical formal grammar for registered classes, or a theorem that handles the sensor experiment as an explicit parameter. Another bounded plant does not answer those questions.
