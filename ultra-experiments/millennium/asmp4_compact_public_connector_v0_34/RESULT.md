# Result v0.34

Compact connected local controllability on the registered public information
state implies the v0.33 safe-closing property.  A finite safe subcover has a
connected overlap nerve; concatenating local connector certificates along a
simple nerve path gives uniform time and separate read/write cost bounds.
Constant connector overhead is sublinear, so the complete nonfinite component
region is the reset-block support region, with an indexed union across
irreversible components.

The public-state qualifier is load-bearing.  The state includes the charged
belief/reachable set and all memories that must be reset.  A two-hidden-mode
witness is physically controllable mode by mode but has no zero-read safe
connector; one charged read bit restores it.  A noncompact ladder has local
unit connectors yet linear return cost, while unsafe overlap and unreset
actuator memory separately break concatenation.

The central harness classifies all 32,768 undirected overlap graphs on six
cover elements, validates 961,344 ordered connector pairs in the 26,704
connected cases, checks an exact rational compact interval cover, and rejects
eight mutations.  An import-independent union-find/Warshall implementation
reproduces the graph census, boundaries, documents, and predecessor inventory.
The explicit 35-package chain passes all 384 tests in 272.34 seconds with
Python bytecode and pytest caching disabled.

This closes the compact local-to-global connector implication and gives an
explicit sufficient formal class for the nonfinite region theorem.  It is not
a full resolution of ASMP-4: deriving robust, finite-cost public local
certificates from the canonical normally hyperbolic plant wording remains
open.
