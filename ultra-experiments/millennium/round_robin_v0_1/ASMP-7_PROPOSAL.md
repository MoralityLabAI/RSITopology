# ASMP-7 proposal: a finite transformation-closed attestation frontier

## Narrow subproblem

Instantiate one non-oracular access class in which compression and decomposition
are real transformations, then compute the **uniform composite** soundness,
privacy, and cost frontier. This addresses ASMP-7's missing worked access class;
it does not resolve the general transformation-semigroup problem.

## Mathematical object and frozen hypothesis

Let the challenge universe be `Z={0,1}^4` with a registered target truth table
`t`. An execution computes a Boolean function `f`. Freeze

- `X0={f: accuracy(f,t)<=8/16}` (compliant),
- `X1={f: accuracy(f,t)>=14/16}` (forbidden capability), and
- a semigroup generated by exact functionality-preserving LUT encoding, RLE
  encoding, Boolean-circuit substitution, two-device XOR-share decomposition,
  cache/memoization, commuting-operation reorder, and trace padding.

The trusted meter's primitive stream contains device ID, opcode class, memory
bucket, message length, timing bucket, and input/output **only for a charged
auditor-issued challenge**. It cannot read `P(f)`, an unmeasured capability,
hidden model state, or execution outside the registered meter boundary.
Signatures authenticate meter packets only; they do not establish semantic
completeness or prove that all capability-bearing execution was metered.

Compare `K_trace`, which releases only primitive trace summaries, with
`K_(m,epsilon)`, which additionally samples `m` public challenges with
replacement and releases trusted-meter correctness bits through randomized
response at per-answer local privacy parameter `epsilon`. For every channel,
construct

`Q_j(K)=cl conv{Law(K|g f): f in X_j, g in G_j(f)}`

and solve one minimax LP whose test satisfies every extreme-law constraint.
Pairwise distances or an average-case classifier are inadmissible substitutes.

**H7-FINITE-1:** at `(alpha,beta)=(0.05,0.05)`, `K_trace` is infeasible,
while at least one charged audit channel on the frozen grid
`m in {0,4,...,128}`, `epsilon in {0,0.25,0.5,1,2,infinity}` is feasible.
The experiment estimates the Pareto-minimal feasible channels, not a
Blackwell-minimal channel beyond this finite registry.

Soundness is reported separately as worst-case false positive and false
negative. Privacy reports the conservative sequential bound `m*epsilon`, the
number of released response bits `m`, and empirical mutual information under a
frozen uniform prior as descriptive only. Normalized charged cost is
`m + (5m)/64 + (3m)/256`: executions, request/response bits, and verifier
operations respectively; the unscalarized tuple is always retained.

## Smallest decisive experiment

Enumerate all 65,536 truth tables and every registered representation. Form the
composite-law polytopes, solve the LPs, and emit primal and dual certificates.
An independent checker evaluates all constraints directly from exact binomial
or rational probabilities.

Controls:

1. **Trace-equivalent impossibility witness:** one `f0 in X0` and `f1 in X1`
   use identical constant-time padded traces. Thus the trace composite sets
   intersect and every trace-only test obeys `FP+FN>=1`.
2. `epsilon=0` makes audit reports independent of correctness and must remain
   infeasible.
3. An unrandomized exhaustive challenge channel is a costly positive-liveness
   control.
4. Transformation labels alone may separate selected pairs but must fail the
   uniform composite gate when any compliant/forbidden laws overlap.

Kill the instrument if any transformation changes `f` or its policy class; any
telemetry field encodes `P(f)` or an uncharged truth table; the trace witness is
not byte-identical; the LP and exhaustive checker differ by more than `1e-10`;
or a claimed feasible test violates either uniform error bound. If no audit
channel passes, the hypothesis is refuted but a valid bounded negative remains.

**Evidence class:** exact/certified for the finite registry if rational checking
passes; otherwise exhaustive-discretized only.

## Optional scale-up

Repeat on an eight-bit challenge universe using a frozen structured class
(sparse DNF, parity, block-LUT, and small circuits), four-device decompositions,
adaptive caching, and correlated meter noise. Use column generation with a
held-out adversarial separation oracle. This is bounded synthetic empirical
evidence, not an exhaustive theorem and not evidence about a real model.

## Consumer and artifact

Consumer: `rsi_topology.attestation`, which may cap a governance use when its
registered telemetry lacks a uniform composite certificate. Reusable artifact:
an execution/transform generator, composite-test LP, independent checker,
`attestability_frontier.json`, and trace-equivalence/dual receipts.

## Claim boundary and reason not to run

Success proves only a finite worked example and validates an instrument. It
does not show that deployed telemetry is complete, that cryptographic integrity
implies semantic coverage, or that real compactified capability is attestable.
The reason not to run it is that much of the finite result may reduce to
textbook minimax testing; if novelty rather than access-class validation is the
priority, external prior-art review has higher expected value.
