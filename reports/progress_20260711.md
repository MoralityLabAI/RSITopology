# Spectral-Bundle Program: 2026-07-11 Checkpoint

## Mathematical update

The working object is now a prompt-indexed spectral bundle, not topology alone
and not a guessed high-dimensional tuple. For each reliability-weighted JSpace
Laplacian, take the frozen low-frequency eigenspace; average its prompt
projectors implicitly; retain directions with occupancy at least `0.75`.
The resulting consensus rank is the empirical dimensionality.

Two uses remain separately gated:

- RL/data allocation uses bundle energy and a KL-bounded exponential tilt.
- Direct edits use signed bundle coordinates and must beat a matched-rank Haar
  subspace on grouped holdouts. Proposals are hashed but never applied during
  discovery.

## Current blocker

No available runtime enforces memory, CPU, and I/O hard caps together. Windows
Job Object memory enforcement failed its probe. WSL memory cgroups work, but
its user manager delegates neither CPU nor I/O; the CPU-quota probe confirmed
the setting was ignored. Docker is absent. The strict WSL wrapper now refuses
to launch rather than degrading to soft limits.

The outcome-free one-prompt registration and write-once registration CLI are
ready. The next model-bearing action requires CPU/I/O cgroup delegation, a
root-owned systemd runner, or an approved container runtime. Even after that,
one prompt can validate only construction and cost; cross-prompt geometry and
held-out causal outcomes remain later gates.

## Bundle-lineage addendum

A scalar analysis of the imported occupancy receipt found three replicated
geometry-pass/utility-collapse transitions from noise `0.35` to `0.5`. Mean
minimum occupancy changed by only `-0.03837`, while mean standardized policy
utility lost `73.36%`; every direct-edit gate flipped from pass to fail. This
does not identify the mechanism, but it falsifies occupancy-plus-rank as a
sufficient utility summary for that fixture.

The proposal-only follow-up treats the missing quantity as bundle lineage:
target-blind chordal overlap and principal-angle retention relative to a frozen
reference, plus the soft operator `P_t P_ref P_t`. It remains descriptive until
replicated real-model outcomes and does not amend any v0.2.1 gate.

## Mechanism correction and within-band control

The imported `files(4).zip` probe identifies the dense transition as
low-to-middle band failover. Low-band rank fell `12 -> 3`; a summary layer then
reported the middle band's healthy rank and occupancy without its label.
Protocol v0.2.2 therefore requires selection-stability warnings and
band-attributed margins while preserving all gates.

The occupancy-matched low-lineage unit control removes that categorical escape:
both conditions select `low` at rank `6`, their full occupancy spectra match to
`8.9e-16`, and candidates/outcomes are identical. Rotating the common subspace
changes planted overlap `0.9972 -> 0.00087`, mean lineage to `0.00123`, and both
downstream gates from pass to fail. This validates synthetic identifiability;
real-model incremental value remains unestablished.
